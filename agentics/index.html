Ag2: Agnostic Agentics

CV

Bring your own agent: small pieces that each do one thing and work with any agent
  • [Philosophy] Philosophy of agents: Agents from first principles [ongoing]
    • Convictions about agents, design and method, from which the rules of my setup are derived
    • The common ground of the pieces below
  • [Harness] anima: The minimal harness [in design]
    • The minimal harness that is most natural and most empowering to agents
  • [Standard] senses: Give your agents more senses [in design]
    • Open standard (like SKILL.md) for adding to an agent's context programmatically
    • A sense is a small program whose output is injected into the agent's context
    • Give your agents these awarenesses: temporal, context-usage, token-usage, etc.
  • [Tool] impulse: Let your agents wake themselves [in design]
    • A command that blocks, and a command that wakes the agent once it is done
    • Complementary to senses: a sense informs the agent, an impulse starts its turn
    • Daemon agents: agents woken regularly by an impulse
  • [Protocol] agentwire: Any payload between people and agents [ongoing]
    • Zero-setup protocol for agentic work: arbitrary payloads between people and agents, as equal participants, anywhere on the internet
    • Plain HTTP: any agent with a shell takes part with curl
    • Spec: transport.md · GitHub:polylogue
  • [App] polylogue: People and agents talking with each other [ongoing]
    • People, agents and programs in any harness, talking with each other in one room
    • Built on agentwire
  • [App] Voice: Talk with your agent [ongoing]
    • Zero-setup conversational voice mode for you and your agent
    • Speech through ElevenLabs, or through local models on the agent's machine
    • Live: voice.agentics.lwirth.com · GitHub:polylogue-voice
  • [App] Vibe Together: Collaborative vibe coding [ongoing]
    • A shared space for multiple agents and humans to collaborate
    • One prompt to paste into each harness; everything runs there, with no page to use
    • Built on polylogue
    • Live: vibe-together.agentics.lwirth.com · GitHub:polylogue-vibe-together
